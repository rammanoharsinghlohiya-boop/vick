# 💗 Ayushi Love Website

A mobile-first romantic gift website made with only HTML, CSS and JavaScript.

## Folder structure

ayushi-love-site/
├── index.html
├── style.css
├── script.js
└── images/
    ├── photo1.jpg
    ├── photo2.jpg
    └── ...

## Add photos

Put Ayushi's photos inside the `images` folder and name them:

photo1.jpg
photo2.jpg
...
photo12.jpg

Then edit the `photos` array at the top of `script.js` if you want more photos or different captions.

You can add 30, 50 or more photos by adding more entries.

## Add your own shayari

Open `script.js` and edit the `shayari` array.

## Add your memories

Edit the three MEMORY blocks in `index.html`.

## Optional music

1. Put `music.mp3` beside `index.html`.
2. In `index.html`, uncomment the `<source>` line inside the audio tag.
3. Tap the music button on the website.

## Run

Open `index.html` in a browser.

For the cleanest experience, use VS Code + Live Server.
